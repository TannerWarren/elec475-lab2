ELEC 475 Lab 2 - exact commands used to produce every result in the report
==========================================================================
Run from the Lab 2 root folder with the virtual environment active:
    .\.venv\Scripts\Activate.ps1        (Windows PowerShell)
Hardware: NVIDIA GeForce RTX 3060 Ti, CUDA build of PyTorch.
All runs: Adam, lr 1e-3, batch size 128, seed 42 unless stated.
Logs were captured by prefixing "python -X utf8 -u" and appending
"2>&1 | Tee-Object -FilePath logs\<name>.log" (see run_all.ps1 / run_extra.ps1);
-X utf8 is needed on Windows so torchinfo's table prints when output is piped.

Code changes to the starter template (see report, Section 3):
  - utils/dataset.py : Tiny ImageNet validation now reads val/images + val_annotations.txt
                       (the template evaluated on the training folder).
  - utils/profiler.py: compare_model_complexities moves each model to the device before profiling.
  - utils/transforms.py: RandomCrop(64, padding=4, reflect) + RandomHorizontalFlip(0.5)
                       + ColorJitter(0.2, 0.2, 0.2) implemented.
